A new job by seashore turns into an awaken nightmare.

## Installing

### Source

1. Clone the source locally with `git clone https://github.com/Nereare/last-hope-shore.git`;
2. Point [Inform 7](https://ganelson.github.io/inform-website/) to open the `.inform` folder.

### Playable File

1. Download the blorb file from the [latest release](https://github.com/Nereare/last-hope-shore/releases/latest) page;
2. Open it with your [favorite interpreter](https://ccxvii.net/gargoyle/).
